DEVELOPER GUIDE

让你的应用，也能画画。

连接授权 VPN 后使用。仅需提示词，无需上传工作流。

1. 提交生成任务 

返回 HTTP 202，包含 id、seed 和 status_url。此接口为异步任务接口，不会在首次请求中返回图片。
参数说明
prompt必填，1–6000 字
modelqwen-image-2.1
size任意宽高（256–2048，8 的倍数），总像素不超过 4,194,304；常用 512x512、1024x1024、1536x1536、2048x2048
steps / seed1–50 步，默认 25；种子 -1 表示随机
n同一提示词一次生成 1–4 张；受批量像素预算限制，适合提高多图吞吐
2. 查询状态与下载图片
每 0.8 秒查询一次：queued 排队中、running 生成中、completed 完成、failed 失败。返回的 progress.current / progress.total 是 ComfyUI 的真实采样步数；队列满时返回 HTTP 429，请按 Retry-After 重试。完成时 data[0].url 及后续 data[].url 是图片地址，失败原因见 error。
